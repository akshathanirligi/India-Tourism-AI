# Core Innovations of the Project

The major innovations of this project include:

- AI-powered personalized tourism recommendation.
- AI conversational travel assistant that asks follow-up questions before making recommendations.
- State-wise and district-wise tourism knowledge base for India.
- AI Travel Notebook with dynamic itinerary generation.
- Budget prediction and expense tracking.
- Personalized recommendations using a user preference dataset collected through Google Forms.
- AI-generated summaries of user feedback and reviews.
- Intelligent suggestions based on weather, weekends, festivals, and user preferences.
- Comprehensive tourism information including history, local foods, hidden gems, and nearby services.
